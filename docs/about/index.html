WolfBoy

WolfBoy reads your code against the law (GDPR, the EU AI Act, CCPA) and against your own privacy policy, and shows you where they disagree. Its rules mark the places in your code that concern the law, on your computer and with no AI, and AI agents in your own Claude Code then read each place and judge whether it is a problem.

How we report what we find

What we find in a project is reported privately to the project first, and made public only after the project has had time to fix it.
